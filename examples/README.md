# 内置示例与演示引导（P1-3）

本目录内置三种语言的「别人风格」待转换样例，用于一键演示完整流程：  
**提取风格 → 查看规则 → 转换代码 → 对照差异**。

## 目录

| 目录               | 文件               | 说明                                      |
| ---------------- | ---------------- | --------------------------------------- |
| `sample_python/` | `messy_demo.py`  | camelCase 命名、2 空格缩进、无空行规范的 Python 样例    |
| `sample_cpp/`    | `messy_demo.cpp` | Allman 括号、tab 缩进、camelCase 命名的 C++ 样例   |
| `sample_java/`   | `MessyDemo.java` | Allman 括号、4 空格缩进、snake_case 命名的 Java 样例 |

## 演示步骤（约 5 分钟）

1. **首页**点击「使用示例演示」，或直接到「提取」页上传某个样例文件；
2. 提取完成后自动跳转「规则」页，查看归纳出的风格规则（低置信度项会高亮）；
3. 也可以直接在「规则」页顶部选用内置预设（PEP 8 / Google C++ / Google Java）；
4. 到「转换」页粘贴代码或选择文件/目录，点击「转换」；
5. 在「对照」页查看并排 diff，确认只有风格变化；`skipped/failed` 条目会标注原因；
6. 点击「采纳导出」下载转换结果（批量为 zip）。

## 安全说明

- 转换前会做语法校验；命中 C++ 函数式宏/模板特化/预处理条件块的文件会被跳过；
- 转换后做等价校验（Python 为 AST 等价，C++/Java 为令牌流等价），失败自动保留原代码；
- 全流程本地离线完成，不发起任何网络请求。
